# E-Textile Heart-Sound Denoising

## Recommended frequency-domain pipeline

The repository now includes a two-channel **neural–adaptive frequency-domain pipeline** for the back-to-back microphone prototype:

- **CardioSpecNet** is a 534k-parameter, reference-conditioned complex-STFT U-Net with compact time/frequency recurrent blocks. It uses exterior-microphone magnitude and energy without assuming sample-level phase coherence.
- **Complex transfer cancellation** estimates a per-frequency exterior-to-chest transfer path over each two-second window.
- **Hybrid fusion** combines both outputs. The default monitoring profile is 55% CardioSpecNet / 45% complex cancellation; a 20% / 80% profile is supplied for closer fidelity to the unfiltered quiet waveform.

On the internal held-out synthetic benchmark, the 55% hybrid reaches 9.287 dB SNR improvement, 6.026 dB SI-SDR improvement, 0.692 correlation, and the best deployable 15–800 Hz log-spectral distance. CardioSpecNet alone has the highest standalone SNR improvement (9.374 dB) and better synthetic 100–800 Hz energy preservation. These are engineering results, not clinical validation.

The original waveform CleanUNet path remains as a legacy baseline. Read:

- [`IMPLEMENTATION_SUMMARY.md`](IMPLEMENTATION_SUMMARY.md) for the deliverable map and primary commands;
- [`REPO_AUDIT.md`](REPO_AUDIT.md) for data/code findings and original-pipeline failure modes;
- [`FREQUENCY_PIPELINE.md`](FREQUENCY_PIPELINE.md) for architecture, profiles, and commands;
- [`RESEARCH_REVIEW.md`](RESEARCH_REVIEW.md) for the literature review and generalization rationale;
- [`BENCHMARK_RESULTS.md`](BENCHMARK_RESULTS.md) for measured results, target sensitivity, and limitations.

## Legacy waveform experiment

Deep learning denoiser for microphone audio collected during motion (running/walking). Uses an **Additive Noise Model** to synthesise training pairs without paired running data:

$$Y(t) = X(t) + N(t)$$

| Symbol | Meaning |
|--------|---------|
| $X(t)$ | Clean body sounds (sitting recordings) |
| $N(t)$ | Pure motion artifact (friction, foot strikes, cable rub) |
| $Y(t)$ | Synthetically mixed noisy signal — model input |

## Quickstart (UW SSH Machine)

### 1. Environment

```bash
# Install uv if needed
curl -LsSf https://astral.sh/uv/install.sh | sh

bash setup_env.sh
source .venv/bin/activate
wandb login
```

### 2. Add your data

See [data/README.md](data/README.md). Windowed npz should be placed under step subfolders, e.g.:

```
data/clean/step_0.1s/train/   data/clean/step_0.1s/val/
data/noise/step_0.1s/train/   data/noise/step_0.1s/val/
```

Available steps: `step_0.01s`, `step_0.1s`, `step_1s` (same participants in each).

### 3. Build synthetic training pairs

Edit the config block at the top of `augment_data.py`, then run:

```bash
python augment_data.py
```

| Setting | Options | Meaning |
|---------|---------|---------|
| `WINDOW_STEP_SECONDS` | `0.01`, `0.1`, `1.0` | Source step folder under `clean/` and `noise/` |
| `SPLIT` | `"train"`, `"val"`, `"both"` | Which splits to synthesise |
| `USE_PREPROCESSED` | `True` / `False` | Target clean type (see below) |

**Mixing modes** (SNR always computed from `X_raw` vs `N_raw`):

- `USE_PREPROCESSED = False` → **X_raw + α·N_raw → X_raw**
- `USE_PREPROCESSED = True` → **X_raw + α·N_raw → X_pre** (same window index)

Both modes apply RMS normalization before saving: `g = rms(Y)`, output is `Y/g` (noisy) and `target/g` (clean).

Other top-level settings: `N_TRAIN`, `N_VAL`, `SNR_MIN_DB`, `SNR_MAX_DB`, `CLEAN_DIR`, `NOISE_DIR`, `OUT_DIR`.

Reads from `data/clean/step_*/{split}/` + `data/noise/step_*/{split}/` (step chosen by `WINDOW_STEP_SECONDS`). Writes `synthetic_data/{train,val}/{noisy,clean}/sample_xxxxx.npy`. See [data/README.md](data/README.md) for folder layout.

### 4. Verify the pipeline

```bash
python scripts/test_data_pipeline.py
```

### 5. Train

**Single GPU:**

```bash
CUDA_VISIBLE_DEVICES=0 python train.py --use_wandb
```

**Multi-GPU (4 × A100):**

```bash
torchrun --standalone --nproc_per_node=4 train.py --batch_size 256 --use_wandb
```

`--batch_size` is **per-GPU**. With 4 GPUs the effective batch is `256 × 4 = 1024`.

**Remote (survives SSH disconnect):**

```bash
bash train_remote.sh      # launches torchrun inside a screen session
tail -f logs/train.log
screen -r etextile_train  # re-attach
```

Edit the top of `train_remote.sh` to change `N_GPUS` or `BATCH_SIZE`.

**Resume from checkpoint:**

```bash
# single GPU
python train.py --resume checkpoints/best.pt --use_wandb

# multi-GPU
torchrun --standalone --nproc_per_node=4 train.py --resume checkpoints/best.pt --use_wandb
```

Checkpoints save the unwrapped model weights (`model.state_dict()`, not `model.module`), so they are portable between single- and multi-GPU runs.

Key model flags:

| Flag | Default | Meaning |
|------|---------|---------|
| `--channels_H` | `64` | Base channel count (doubles each encoder layer, capped at 768) |
| `--encoder_n_layers` | `8` | U-Net depth D |
| `--tsfm_n_layers` | `3` | Transformer depth N |
| `--tsfm_d_model` | `512` | Transformer token dimension |

Key loss flags:

| Flag | Default | Meaning |
|------|---------|---------|
| `--si_snr_weight` | `1.0` | Weight on −SI-SNR term |
| `--mr_stft_weight` | `1.0` | λ₁ for multi-resolution spectral loss |
| `--diff_l1_weight` | `0.1` | λ₂ for temporal-derivative L1 |

### 6. Run inference

```bash
PYTHONPATH=. python scripts/run_inference.py \
  --input      data/test_real/walking/step_0.1s/heart_w1_windows.npz \
  --checkpoint checkpoints/best.pt \
  --start 0 --end 10
```

`--start` / `--end` select a time window in seconds (default: `0`–`20`). Output directory defaults to `outputs/<stem>_<start>-<end>s`.

Input: a windowed `.npz` from `data/test_real/walking/step_*/` (key `"x"`, shape `(N_windows, window_size)`, int16 scale).

Outputs: `original_noisy.wav`, `predicted_clean.wav`, `comparison.png`

## Model

**CleanUNet** — a 1-D U-Net with a causal Transformer bottleneck, operating directly on waveform samples (NVIDIA, ICASSP 2022).

```
Noisy waveform  [B, 1, T]
      │
      ▼  per-utterance std normalisation
      │
   Encoder (D = 8 layers)
   Conv1d(stride=2) → ReLU → Conv1d(1×1) → GLU
   Channels: 1 → 64 → 128 → 256 → 512 → 768 → 768 → 768 → 768
      │  (additive skip connections saved at each level)
      ▼
   Bottleneck: N-layer Transformer (causal self-attention)
   1×1 Conv → [B, L, 512] → Multi-Head Attn × 3 → [B, 512, L] → 1×1 Conv
      │
      ▼
   Decoder (D = 8 layers, mirrored)
   Skip added → Conv1d(1×1) → GLU → ConvTranspose1d(stride=2) → (ReLU)
   Channels: 768 → 768 → 768 → 768 → 512 → 256 → 128 → 64 → 1
      │
      ▼  crop to original length + restore loudness
      │
Clean waveform  [B, 1, T]
```

Default config: `channels_H=64`, `encoder_n_layers=8`, `tsfm_n_layers=3` ≈ **40 M parameters**.

## Loss

Hybrid loss combining a perceptual metric, spectral fidelity, and waveform-derivative regularisation:

$$\mathcal{L} = -\text{SI-SNR}(\hat{X}, X) + \lambda_1 \mathcal{L}_{\text{Multi-STFT}}(\hat{X}, X) + \lambda_2 \mathcal{L}_{1}(\Delta\hat{X}, \Delta X)$$

| Term | Default weight | Purpose |
|------|---------------|---------|
| $-\text{SI-SNR}$ | 1.0 | Primary perceptual metric; scale-invariant, maximised during training |
| $\mathcal{L}_{\text{Multi-STFT}}$ | λ₁ = 1.0 | Log-magnitude L1 at FFT sizes 512 / 1024 / 2048 |
| $\mathcal{L}_1(\Delta\hat{X}, \Delta X)$ | λ₂ = 0.1 | L1 on first-order differences — preserves sharp heart-sound onsets |

**SI-SNR** (Scale-Invariant SNR) projects the estimate onto the target, then measures the signal-to-noise ratio of the aligned component:

$$\text{SI-SNR} = 10 \log_{10} \frac{\|s_{\text{target}}\|^2}{\|e_{\text{noise}}\|^2}, \quad s_{\text{target}} = \frac{\langle\hat{x}, x\rangle}{\|x\|^2} x$$

**Differential L1** penalises errors in $\Delta X(t) = X(t) - X(t-1)$. For contact-mic heart sounds, sharp onsets (S1/S2 boundaries) produce large $\Delta X$ spikes — this term prevents the model from smearing them.
